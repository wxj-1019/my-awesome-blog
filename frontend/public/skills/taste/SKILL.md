# taste

> 站内策展副本，以官方仓库为准。来源：https://github.com/Leonxlnx/taste-skill

## 定位

把「一眼 AI」的模板味，炼成真正的设计品味。编码 Agent 在动手前先审稿、再编码。

## 何时使用

- 新页面临启动，怕写出来一股模板味
- 作品被吐槽「一看就是 AI 做的」，想找病根
- 重构老页面，想顺便把审美也升级一遍
- 给 Agent 立一套设计规矩，让它不再自由发挥

## 核心约束

1. 审美规则化：布局节奏、字体层次、配色语义写成可执行指令
2. 先审后写：生成代码前先评估设计方案
3. 框架无关：React / Vue / Svelte / 原生 HTML 均适用
4. 拒绝默认蓝紫渐变与居中大标题套路

## 示例提示

```
用 taste 的标准审视这个落地页，指出最「一眼 AI」的三处并重构它们
```

```
为我的摄影作品集设计首页，要有编辑杂志般的排版呼吸感
```
