# superpowers

> 站内策展副本，以官方仓库为准。来源：https://github.com/obra/superpowers

## 定位

让 Agent 先想清楚，再动手写代码。把 brainstorm、写计划、执行计划、系统化调试、TDD 等工程纪律装进工作流。

## 何时使用

- 需求刚到手上，想让 Agent 先盘清楚再动手
- 大重构心里没底，需要一份能逐步验证的执行计划
- bug 反复修不好，想戒掉「改一下试试」的玄学调试
- 给 Agent 装上整套工程纪律，而不是每次都口头叮嘱

## 核心能力

1. 完整工作流闭环：brainstorm → write-plan → execute-plan
2. 强制工程纪律：先规划、先测试，减少返工
3. 系统化调试：先定位根因再修复
4. 模块化组合：可按需取用单个 skill

## 示例提示

```
别急着写代码，先按 superpowers 的流程和我 brainstorm 这个需求
```

```
为这次重构写一份执行计划，拆成可以逐步验证的小任务
```
