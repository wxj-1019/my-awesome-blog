# brainstorm

> 站内策展副本，以官方仓库为准。来源：https://github.com/obra/superpowers

## 定位

把脑子里那团雾，澄清成可执行的规格。面对模糊念头时连续追问目标、约束与边界。

## 何时使用

- 脑子里只有一个模糊念头，说不清到底要做什么
- 想法太多太散，需要有人帮忙收敛成一个方案
- 开工前想先把隐含假设和边界都逼问出来
- 写好了点子却落不了地，想要一份能直接开发的规格

## 核心能力

1. 追问式澄清：逼出隐含假设与真实约束
2. 从发散到收敛：先拓宽可能性，再收敛方案
3. 输出即规格：产出可指导开发的结构化文档
4. 与 write-plan 等后续流程衔接

## 示例提示

```
我想给博客加一个「灵感速记」功能，但还没想清楚，帮我 brainstorm 一下
```

```
围绕「让老用户回来」这个目标做一轮头脑风暴，最后收敛成一个可执行方案
```
