## 产品概述

解决后端服务启动时的环境变量文件编码错误

## 核心功能

- 将 backend/.env 文件从 UTF-16 LE 编码转换为 UTF-8 编码
- 验证转换后的文件格式正确性
- 测试后端服务能否正常启动

## 技术栈

- Python 3.x（用于编码转换脚本）

## 实现方法

1. 使用 Python 内置的 `codecs` 模块读取 UTF-16 编码的 `.env` 文件
2. 将内容写入为 UTF-8 编码（不保留 BOM）
3. 验证文件转换成功
4. 测试后端启动

## 实现细节

### 编码转换脚本

创建临时脚本 `convert_env_encoding.py`，使用以下逻辑：

```python
import codecs

# 读取 UTF-16 LE 文件
with codecs.open('backend/.env', 'r', encoding='utf-16') as f:
    content = f.read()

# 写入 UTF-8 文件（不保留 BOM）
with codecs.open('backend/.env', 'w', encoding='utf-8') as f:
    f.write(content)
```

### 关键点

- 使用 `encoding='utf-16'` 自动处理 BOM 识别
- 目标编码使用 `encoding='utf-8'` 不带 BOM
- 转换前可以备份原文件

### 验证步骤

1. 转换后读取文件验证 UTF-8 编码
2. 尝试启动后端服务确认问题解决
