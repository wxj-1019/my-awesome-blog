## 修复计划

### 问题分析

1. **数据库表不存在**：`weather` 表未创建，导致查询失败
2. **天气 API 配置缺失**：`ALAPI_TOKEN` 未配置，导致 API 返回 400 错误

### 修复步骤

1. **运行数据库迁移**
   - 在后端目录执行 Alembic 迁移来创建 `weather` 表
   - 命令：`cd backend && alembic upgrade head`

2. **配置 ALAPI_TOKEN（可选）**
   - 如果需要天气功能，在 `backend/.env` 文件中添加：
   ```
   ALAPI_TOKEN=your_alapi_token_here
   ```
   - 如果不需要天气功能，可以跳过此步骤

3. **验证修复**
   - 重启后端服务
   - 检查前端天气卡片是否正常显示
