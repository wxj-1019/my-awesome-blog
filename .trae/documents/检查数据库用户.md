## 检查数据库中的 admin 用户

**目标**: 查询 PostgreSQL 数据库中是否存在 admin 用户

**步骤**:
1. 创建一个查询脚本，连接到数据库并查询 users 表
2. 显示所有用户信息（username, email, is_active, is_superuser）
3. 如果没有用户，可以运行 `create_admin_user.py` 脚本创建

**数据库信息**:
- 连接: `postgresql://postgres:123456@localhost:5432/my_awesome_blog`
- 表名: `users`
- 需要查询的字段: username, email, is_active, is_superuser

**预期结果**:
- 如果有 admin 用户，显示其信息
- 如果没有用户，提示创建
