# 塔罗牌与生图页面 UI/UX 优化设计

日期：2026-08-09  
范围：`/tools/tarot`、`/tools/image-gen`

## 1. 目标

在不改变现有业务流程、API、持久化历史和生成状态机的前提下，优化两个工具页的首屏信息层级、操作聚焦、响应式布局和状态反馈。保留项目既有的深海氛围、玻璃拟态、语义 token、Lucide 图标与 reduced-motion 约束。

共同原则：

- 首屏只突出当前最重要的一个动作。
- 次要能力仍可达，但不与主流程竞争视觉权重。
- 桌面端利用侧栏和 sticky 布局，移动端按自然操作顺序纵向排列。
- 不新增后端接口、不改变数据结构，不引入新的状态管理或依赖。

## 2. 塔罗牌页

### 2.1 布局

保留现有四阶段状态机和“占卜 / 牌义速查”视图切换。占卜视图改为明确的工作流层级：

- 页头下方保留紧凑进度条。
- `ask` 阶段的主卡只承载问题输入、牌阵选择和开始按钮。
- “今日之牌”保留为主卡上方的辅助入口，改成更紧凑的横向提示区，不与问牌卡争夺主 CTA。
- 首次引导合并为主卡内的简短提示，避免独立横条造成首屏堆叠；关闭后继续使用现有 localStorage 标记。
- 桌面端保持“进度侧轨 + 主流程 + 历史侧栏”，但历史只作为辅助栏，移动端继续放在结果/统计之后。

### 2.2 交互

- 问题输入保留可选语义和 200 字限制。
- 牌阵选项强化选中态、牌数信息和可点击面积，开始占卜按钮保持全宽主操作。
- 抽牌阶段在牌堆上方突出“已选 / 总数”，在牌堆下方统一放置“代我抽牌”和“撤销”操作；重新开始作为低强调次操作。
- 翻牌阶段保留逐张揭示、全部翻开和点击单牌翻开；全部翻开后自动滚动到解读区。
- 结果区用更清晰的标题、牌位标签和解读起点，统计与历史继续降级到解读后的辅助信息。

### 2.3 响应式与无障碍

- 移动端问牌卡先出现，今日之牌不超过一行半视觉高度；进度条触控目标保持至少 44px。
- 桌面端侧轨 sticky，主流程最大宽度受控，避免牌面过度拉伸。
- 保持现有 tab、键盘快捷键、aria-live、focus-visible 和 reduced-motion 行为。

## 3. 生图页

### 3.1 布局

保留左侧输入、右侧创作画布的工作台结构。调整左侧信息层级：

- 图片 / 视频切换作为输入卡的第一控制。
- 提示词输入、示例提示词和生成按钮组成核心操作区。
- 模型、参考图、画幅、张数归入“生成设置”次级区，默认展开图片常用设置但视觉弱化；视频模式隐藏不相关设置。
- 参考图预览、URL、上传入口保持现有能力，使用统一的设置区分隔和状态反馈。
- 结果画布保留“结果 / 历史”双 tab，但结果内容层级更明确：空态灵感、生成进度、错误重试、成功结果分别有明确标题和留白。
- 生成记录抽屉继续保留作为跨页面历史入口，避免移除已有恢复和账户信息能力。

### 3.2 交互

- 主 CTA 文案随图片/视频、文生图/图生图和生成状态变化。
- 生成中仍可取消；错误状态直接提供重试。
- 结果区明确展示生成数量、媒体类型、预览和下载入口。
- 示例提示词继续支持一键回填，并将焦点归还到提示词输入框。
- 历史恢复后自动切回结果 tab，保持现有行为。

### 3.3 响应式与无障碍

- 移动端按“类型 → 提示词 → 设置 → 生成 → 结果”顺序呈现；桌面端保持结果画布 sticky。
- 设置控件触控尺寸不低于 44px；输入均有 label 或 aria-label。
- 图片继续提供 alt，结果网格和下载操作保持键盘可达。
- 不增加持续循环动画；现有进度动效遵守 reduced-motion。

## 4. 实现边界

预计修改：

- `frontend/src/app/tools/tarot/tarot-content.tsx`
- `frontend/src/components/tarot/` 中与牌位/提示区直接相关的展示组件（如确有必要）
- `frontend/src/app/tools/image-gen/image-gen-content.tsx`
- `frontend/src/components/tools/image-gen/CanvasStage.tsx`
- 必要时调整 `HistoryList.tsx` 的视觉层级

不修改：

- 后端 API、RunningHub 工作流参数和轮询逻辑
- localStorage 数据格式
- 全局主题 token 与共享页面壳
- 与这两个页面无关的组件或历史未提交资源

## 5. 验收标准

- 两个页面首屏均能明确识别主任务和主 CTA。
- 塔罗牌流程四阶段无行为回归，问题、牌阵、抽牌、翻牌、解读、历史均可使用。
- 生图图片/视频、文生图/图生图、取消、重试、历史恢复和账户抽屉均可使用。
- `npm run lint`、`npm run type-check` 和相关测试通过。
- 至少检查桌面宽度（约 1280px）与移动宽度（约 390px），无横向溢出、控件重叠或文字截断异常。
- reduced-motion 下不出现新增的强制动画。
