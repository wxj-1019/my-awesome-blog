方案 A · 现网增强

浅：天光 + 双日光柱 + 云影；深：双月光斑 + 月路 + 荧光点。最贴近当前 AmbientBackground 与 Hero 气质。

方案 B · 雾气水面

大块柔雾呼吸，几乎无硬几何柱。最「安静」，适合怕花的浅色模式。

方案 C · 柔极光

横向极淡光带 + 地平线，略电影、仍克制。深色像月云流动，浅色像晨雾彩光。

方案 D · 极简

仅双光斑慢漂 + 极稀气泡。性能最稳，做默认兜底很合适。
